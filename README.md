# 🔮 피클 홀로그램 · 4면 피라미드

투명 플라스틱 사각뿔(피라미드)을 iPhone 화면 위에 올려놓고 보는 **4면 홀로그램 웹앱**입니다.
화면 4분면이 각각 피라미드의 네 면에 반사되어, 가운데에 떠 있는 피클을 볼 수 있습니다.

**▶ https://r1axodn.github.io/pickle-hologram/**

## 쓰는 법

1. 아이폰에서 위 주소를 열고, 페이지를 홈 화면에 추가하면 전체 화면으로 뜹니다.
2. 투명 아크릴/플라스틱 사각뿔을 화면 **한가운데**에 올립니다.
3. 화면 아래 `GAP`(4면 사이 간격)과 `SIZE`(내용 크기)를 눌러 반사가 딱 맞게 조절합니다.
4. 거울상이 어색하면 `FLIP X` · `180°`로 반전을 보정합니다.
5. 방을 어둡게 할수록 홀로그램이 선명합니다.

## 기능

| 모드 | 내용 |
|---|---|
| **피클** | 하와이안 피자의 피클(흰 몸통 · 라임 글로우 · 깃털 귀) + 마이크 반응형 라임 코어 링. 말하면 링·입·눈이 반응하고, 마이크를 안 쓰면 숨쉬기·눈깜빡임 아이들 애니메이션. |
| **D-DAY** | 실시간 시계 + 단대부고 2학기 기말고사(2026-12-08) · 2028학년도 수능(2027-11-18) 카운트다운 |
| **타이머** | 25분 뽀모도로 / 스톱워치, 시작 · 일시정지 · 리셋 |

- `📞 피클 부르기` — `pickle://call` 로 피클을 호출합니다.
- `숨기기` — 컨트롤을 모두 감추고 홀로그램만 남깁니다(오른쪽 아래 `⋯` 로 복귀).
- 설정(간격 · 크기 · 반전 · 모드)은 기기에 저장됩니다.

## 파일

- `index.html` — 화면 골격 (4분면 캔버스 · 컨트롤)
- `style.css` — 순수 검정 배경, 반사 방해 없는 저채도 컨트롤
- `app.js` — Web Audio 마이크 분석, 캐릭터/코어/HUD/타이머 렌더링, 캘리브레이션
- `favicon.svg`

의존성 없는 정적 페이지입니다.
